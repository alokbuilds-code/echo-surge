# ECHO SURGE

**Kinetic Reflex Arcade**

https://echo-surge.vercel.app/

A minimalist, high-precision reflex arcade built entirely with **HTML5, CSS3, and Vanilla JavaScript**.

ECHO SURGE combines fluid physics, procedural audio, escalating hazards, and time-bending abilities into a fast, responsive arcade experience.

---

## ✦ Features

* **Kinetic Movement** — Smooth physics-based player control with momentum and inertia.
* **Energy Shards** — Collectible shards with magnetic attraction and combo-based progression.
* **Chrono Pulse** — Slow time and destroy nearby hazards with a charged shockwave.
* **Dynamic Feedback** — Screen shake, particle bursts, spring animations, and responsive HUD feedback.
* **Procedural Audio** — Real-time sound effects generated entirely through the Web Audio API.
* **Combo System** — Progressive multipliers from `1X` through `32X HYPERDRIVE`.
* **Three Game Modes** — Classic, Hyperdrive, and Zen Flow.
* **Responsive Controls** — Mouse, touch, keyboard, and double-tap interactions.
* **60 FPS Rendering** — Lightweight canvas-based game loop with no external game engine.

---

## ◇ Game Modes

| Mode           | Experience                                                    |
| -------------- | ------------------------------------------------------------- |
| **Classic**    | Escalating hazards with three shield points.                  |
| **Hyperdrive** | Maximum velocity from the beginning for pure reflex gameplay. |
| **Zen Flow**   | Non-lethal continuous gameplay with infinite shields.         |
